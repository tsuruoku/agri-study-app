# 野菜の学習（個人用）

日本語の農業試験対策を行う、個人用・オフライン対応のPWAです。
依存関係はなく、素のESモジュールだけで動きます。

## 構成

- `web/` — アプリのシェル（HTML/CSS/JS・Service Worker）。公開してよいのはこの中身だけです。
- `scripts/` — `build.mjs`（`dist/` への許可リストビルド）、`serve.mjs`（127.0.0.1:4173 で `dist/` のみ配信）。教材パック作成スクリプト（`prepare-content*`）は未作成。
- `tests/` — Node 標準テストと Chrome CDP スモーク。フィクスチャは人工データのみ。
- `private-content/` — 教材の原本・パック（配布しない・gitにも入れない）。
- `dist/` — ビルド成果物。シェルだけが入り、教材・記録・テストは含まれません。

## ローカルでの確認

```sh
node scripts/build.mjs   # web/ の許可リストを dist/ にコピー（不明な dist エントリで失敗）
node scripts/serve.mjs   # http://127.0.0.1:4173/ で dist/ のみ配信
node --test tests/*.test.mjs
node tests/browser-check.mjs   # serve.mjs が動いている状態で実行
```

## 教材ファイルの読み込み

`.agristudy` 形式のJSONを設定画面・ホーム画面の「教材ファイルを取り込む」から選びます。
内容は読み込み前に全体を検証し、形式・参照・チェックサム・サイズを確認してから確認画面を表示します。失敗しても現在の教材・記録は残ります。ファイルは端末内だけで使われ、送信されません。

## バックアップと復元

設定画面から全記録＋教材を含む `.agristudy`（JSON）を保存できます。
このファイルは暗号化されていません。著作物と学習記録を含むので保存先に注意してください。
復元は内容の確認画面で確かめてから実行し、現在の記録をすべて置き換えます。
ブラウザのデータ消去や容量不足でIndexedDBの記録が消えることがあるので、定期的にバックアップしてください。

## 公開・更新について

このアプリの記録は origin に紐づきます。ホスト名・ポート・http/https が変わると
保存データにアクセスできなくなります（バックアップからは復元できます）。
公開する場合は同一のHTTPS origin での運用を前提にし、変更時は事前バックアップ→復元の手順が必要です。
HTTPS での一般公開は別途の合意があった場合のみ行います。

## テスト

- `node --test tests/*.test.mjs` — パッケージ検証・ストレージ・タイマー・ビルド・Service Worker・core（リード管理）のユニットテスト。
- `node tests/browser-check.mjs` — 起動・取り込み・回答・バックアップ往復・記録・オフライン再読込を実際のChromeで確認。
